# Guess the Number

A browser number-guessing game: one secret number, a handful of tries, instant feedback.

## What it does

The page picks a number and you narrow it down. Each guess comes back as higher or lower, and the attempt count keeps you honest.

## Run locally

Open `guess.html` in a browser - there is no build step and nothing to install.

## Files

| File | Purpose |
| --- | --- |
